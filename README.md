
# 🚦 Smart City Traffic Management and Route Optimization System

A Python-based academic project demonstrating how graph algorithms can be used to represent road networks, explore connectivity, calculate shortest paths and identify minimum-cost network structures.

**Shashank Tyagi**

## 🎯 Project Objectives
- Represent a road network using graph data structures.
- Explore locations using BFS and DFS.
- Calculate shortest routes using Dijkstra's algorithm.
- Generate a Minimum Spanning Tree using Prim's algorithm.
- Analyze network connectivity and route costs.

## 🛠 Technologies Used
- Python 3
- Graph Theory
- Data Structures and Algorithms
- CSV

## 📚 Algorithms Implemented

| Algorithm | Purpose |
|---|---|
| BFS | Breadth First Search |
| DFS | Depth First Search |
| Dijkstra | Shortest Path |
| Prim | Minimum Spanning Tree |
